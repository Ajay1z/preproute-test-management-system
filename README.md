# Preproute Test Management System

Production-ready React 18 + TypeScript + Vite frontend for the Preproute test management assignment.

## Stack

- React 18
- TypeScript
- Vite
- React Router DOM
- Axios
- Zustand
- React Hook Form
- Zod
- React Toastify
- Tailwind CSS

## Setup

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

Backend API base URL:

```text
https://admin-moderator-backend-staging.up.railway.app/api
```
